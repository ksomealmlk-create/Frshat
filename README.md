# الملحمة البيضاء ⚪🦷
لعبة Idle/Clicker بالعربي: نظّف الأرضية، اشتر آلات وفرش، وافتح رسائل الجد عبر 5 مناطق من المستودع إلى الكون.

## المميزات
- نقر + آلات تشتغل تلقائياً + تطوير لحد مستوى 100
- أرباح أثناء الغياب (لحد 8 ساعات)
- 5 مناطق، لكل منطقة لون أرضية ورسالة من الجد (تبويب «رسائل الجد»)
- تأثيرات نقر (أرقام طايرة) ولمعة للأماكن المنظفة
- مديرون (أتمتة الشراء)، معززات، إنجازات، تسليم الفرشاة (Prestige)، إعدادات
- حفظ تلقائي + زر «بدء من جديد» + نهاية للقصة

## البناء (APK) عبر GitHub
1. ارفع المحتوى لمستودع GitHub على الفرع `main`.
2. من تبويب **Actions** شغّل **Build APK**.
3. نزّل `white-epic-apk` من Artifacts.
